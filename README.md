# Profile Picture Upload Sample (Cloudinary)

## Setup

1. Install dependencies:
   ```
   npm install
   ```
2. Create a `.env` file with your Cloudinary credentials (already set up by default):
   ```
   CLOUDINARY_CLOUD_NAME=dabudhnss
   CLOUDINARY_API_KEY=419127198944656
   CLOUDINARY_API_SECRET=bvwBT7uUPJ_NULb7SoaFqxTLoXc
   ```
3. Start the backend server:
   ```
   node server.js
   ```
4. Open `index.html` in your browser.

## Usage
- Select an image and click Upload.
- The image will be uploaded to Cloudinary and displayed on the page.
